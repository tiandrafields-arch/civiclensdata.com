# CivicLens Data

**Government data is public. We make it powerful.**

This repository hosts the public launch site for [CivicLens Data](https://civiclensdata.com), an AI-powered civic data platform that transforms raw government data into community-legible policy impact tools for advocacy organizations, legal teams, and investigative journalists.

## About the Platform

CivicLens Data operates on a simple principle: AI is the engine, never the driver.

- **Human layer:** Equity frameworks, domain expertise, legal context mapping, and community translation standards govern every analysis
- **AI layer:** Automated data ingestion, spatial pattern detection, plain-language summarization, and document generation
- **Transparency:** Every output ships with full AI transparency disclosure and human review before publication

The methodology was built and validated through live legislative battles in Louisiana, including safety net policy analysis and post-*Callais* redistricting equity work.
